# Official Black Ice UI Version 1

These are the user-selected phone and desktop design references, recovered on 2026-10-16. Preserve this direction; V2/V3 are not current designs.

- `v1/phone.png`: original 1000009084.png, 864×1536 (9:16).
- `v1/desktop.png`: original 1000009085.png, 1536×864 (16:9).

Keep the mountain mark, black/navy surfaces, icy-blue active controls, thin line icons, large undistorted preview, thumbnail tracks with a fixed label gutter, compact editing shortcut strip and readable panels. Phone navigation lives at the bottom; wide mode uses a left media browser and right inspector. Both retain UI Lock and automatic/manual mode selection.

v1.0.1 adds line icons, shortcuts, a preview scrubber, fixed track labels and more timeline space to match the reference structure. The screenshots are concept art: do not implement fake toggles, fake media, a decorative OS taskbar, or buttons for unavailable tools. v1.0.2 adds the responsive two-column desktop media grid, type filters and filename search. Further differences (dedicated project-flow screen and category-specific inspector) are follow-up work; do not claim a pixel-perfect copy.
